# Reflection

## What advice would you give yourself if you were to start a project like this again?
One thing I would maybe tell myself would be to work on it more on my own time. I was basically solely using the time I had in class in order to work on my project, as there were other things I was more prioritized on for using my free time on. 

I think if I was able to give myself that extra time to work on the project, I would've been able add more features, especially those in my nice-to-have list, or even a completely different game with more complex mechanics and requirements.

Regardless I think its neat I was able to add what I was able to despite having less time.

## Did you complete everything in your "needs-to-have" list?
Yes, I was able to complete everything in my needs-to-have list, alongside a few things part of my nice-to-have list.

## What is your favourite part of the project?
There's a few things that I particularly like about my project, with the one being the wave spawning system.

I like how effective it is despite its more simplistic design, and how I was able to add a few more parts to it, such as requriments to start the next wave (ie. less than number of enemies requirement).

I think another thing may be me adding the ability to switch weapons in the game. I think the bombs came out really well, and I like how I was able to implement them (may need a bit of a balance change though).

## What was the hardest part of the project?
It's either between designing the wave-spawning system or debugging and trying to fix issues with my game.

I didn't entirely understand how I could make a wave system so I needed some guidence, but once I did understand what I could do, it was easier to go from there.

Debugging was probably more difficult though, as there were times where I didn't understand why certain parts of my code weren't working and it was super annoying and difficult for me to figure out why it wasn't working and what I could do to fix this. Some examples of this include those from the next question.
